p5js.live

Live-code visuals with JavaScript and p5.js.

Build, remix, and perform audio-reactive graphics in the browser.

p5js.live turns p5.js into a live visual instrument. Write ordinary JavaScript, evaluate changes while your performance keeps running, combine visual patches into scenes, react to sound, add shaders, and stream visuals between performers.

Launch p5js.live View on GitHub

Code while it's running.

No stop-build-reload cycle.

Put your cursor in a patch, hit Cmd/Ctrl+Enter, and your new code takes over immediately. If something fails, the last working version keeps running.

That means you can experiment on stage without constantly restarting the piece.

function pulse({ time, audio }) {
  const size =
    80 +
    sin(time * 2) * 30 +
    audio.bass * 160;

  circle(width / 2, height / 2, size);
}

It's still p5.js.

There's no new visual language to learn.

Use the p5 functions you already know — circle(), fill(), noise(), width, height, and the rest — with ordinary JavaScript functions, objects, and classes.

p5js.live adds the live-performance layer around them.

Make visuals react to sound.

Every patch can receive live audio information including:

  • overall level
  • bass, mid, and treble energy
  • beat detection
  • FFT spectrum data
  • waveform data

Use continuous audio values for movement and distortion, or beats for events and transitions.

Choose an audio file, use the microphone, or perform with no audio at all.

const size = 40 + audio.bass * 220;
const wobble = sin(time * 2 + audio.mid * 3);
const flash = audio.beat ? 255 : 30;

Build performances from patches.

A patch is a small visual behavior.

A scene is simply an array of patches in layer order.

Add, remove, reorder, and rewrite pieces while the scene is running.

Small patches stay reusable. Scenes stay easy to understand. And you can gradually build a personal library of visual material for performance.

const scene = [
  solidBackground,
  waveScope,
  rings,
  plasma
];

activate(scene);
const spin = new ShaderChain()
  .rotate(({ time, audio }) =>
    time * 0.15 + audio.bass * 0.3
  )
  .scale(({ audio }) =>
    1.02 + audio.mid * 0.08
  )
  .hue(({ time }) =>
    time * 0.03
  );

Go beyond the canvas.

Use ShaderChain to process the pixels already drawn by your scene.

Rotate, scale, distort, shift hue, and build effect chains whose parameters can change with time or audio.

Put the effect into your scene like any other patch.

Perform together.

Networked visual streaming is built in.

Publish the output of one canvas and it becomes available to other performers in the same room.

A second performer can add that stream to their own scene like another visual source — then layer over it, transform it, or feed it into shaders.

You aren't sharing code.
You're sharing the live visual output.

That opens up performances where multiple people build one distributed visual system from separate browsers.

Designed for live coding.

p5js.live includes the things that matter when you are changing code in front of an audience:

Live evaluation

Run one patch or the complete editor without restarting the performance.

Failure recovery

Bad code leaves the last successful version running whenever possible.

Safe state

Capture a working performance and return to it instantly.

Patch library

Install reusable patches and add them directly to scenes.

Persistent state

Let patches maintain trails, histories, particles, and other state across frames.

Audience view

Send the visuals to a clean presentation window without the editor.

From sketch to performance.

You can start with something as small as:

({ time, audio }) => {
  circle(
    width / 2,
    height / 2,
    80 + audio.bass * 120
  );
}

Then add another patch.

Then a shader.

Then an audio source.

Then another performer's stream.

The same environment scales from experimenting with one p5.js sketch to building an entire live audiovisual performance.

Open source. Built for experimentation.

If you already know some JavaScript or p5.js, you can start immediately.
