# Deferred Patch Library Ideas

These ideas are intentionally saved for a later Patch Library design pass. They are
not part of the folded-editor **＋ New patch** change:

- Add a **Project patches** Library section for handwritten project patches.
- Add a **Save to My Library** action.
- Add a Library **Remove from scene** action.
- Add an **Uninstall source** action.

The later design should keep the existing lifecycle distinctions explicit: creating
source, installing reusable source, placing an object in a scene, evaluating a scene,
and saving something for reuse are different operations.
